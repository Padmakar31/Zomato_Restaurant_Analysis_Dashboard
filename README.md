# Turning Restaurant Data into Business Insights

**Project Type:** Data Analytics | Business Intelligence | Data Visualization

**Tools & Technologies:** Power BI • Tableau • SQL • Microsoft Excel

---

## 📌 Project Overview

The **Zomato Global Restaurant Analytics Dashboard** is a data analytics project designed to explore restaurant industry trends across countries, cities, and geographical markets represented in the dataset.

The project focuses on understanding restaurant performance, customer ratings, cuisine preferences, pricing patterns, service availability, and geographical distribution. By transforming raw restaurant data into meaningful visualizations and analytical insights, this project demonstrates how data analytics can support business intelligence and data-driven decision-making.

Using Power BI, Tableau, SQL, and Microsoft Excel, the project combines data preparation, analytical querying, exploratory data analysis, and interactive dashboard development to uncover patterns in the restaurant industry.

The primary objective is to convert restaurant data into clear, actionable insights that help stakeholders understand market characteristics, compare restaurant performance, and explore opportunities for business improvement.

> **Scope:** Worldwide analysis refers to the global scope of the project. Actual country and city coverage depends on the dataset available for analysis.
